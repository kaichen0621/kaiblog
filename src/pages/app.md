## 這是我在 Mac 上的軟體清單

# macOSAPP
1. Addictive Drums 2 Demo : 好用鼓音源，五月天用
2. After Effect : 製作特效軟體
3. Media Encoder 2026 : 用 `Adobe` 的軟體匯出好像得用它
4. Affinity : 製作縮圖常用
5. Anytype : 超好用開源筆記軟體，載入速度極快、同步方便！
6. Aria Player : `Finale` 的 音源工具之類的吧？
7. Asyar : 開源啟動器，不會被綁架～！
8. Audacity : 免費開源超好用的音訊編輯器
9. Brave Origin : 超好用的乾淨瀏覽器！只佔 433.8 MB 
10. ClipGrab : 下載任何影片超好用！包含 B 站之類的
11. Cubase 15 : 主要的編曲軟體，教學資源不錯
12. DaVinci Resolve 21 : 找不到比他更好的調色與剪輯軟體了
13. Discord : 聊天與語音頻道首選
14. Dorico 6 : 最近想刪除的打譜軟體，超級難用，還是喜歡 musescore
15. Final Cut Pro : 剪輯簡單快速影片時很好用、有效率！但是我不太會用
16. Finale 27 : 停止提供更新了，最近沒什麼在用
17. Gemini : 那個… 要 AI 得時候挺方便的，而且很快速 (我設定 按右邊兩下 command)
18. GIMP : 曾老師教學的圖邊軟體，超好用！
19. Groove Agent SE : Cubase 內建的鼓機
20. Guitar Rig 7 : Kontakt 免費送的效果器，很高級很好用
21. HALion Sonic : Cubase 內建音源，電量低
22. HandBrake : 處理影片畫質開源好幫手！
23. IINA : 開源萬能播放器，Mac 必裝
24. iZotope RX 12 : 處理人聲超級好用的工具，最近砸到第12版了
25. Keka : 超好用壓縮工具！RAR 打得開～
26. Keynote : 蘋果簡報工具
27. Kontakt 8 : 強大的採樣音源主機
28. Line : 必要但笨重的通訊軟體
29. LocalSend : 傳輸檔案好工具
30. Logic Pro : 蘋果自家 DAW，想刪除了！ (錄音老師推薦不要刪)
31. MAWxFF : 自動字幕，目前還在研究
32. Melodyne Element : 修音必備好用插件 建議別用，因為 M 晶片不支援 😭
33. Microsoft Excel : 強大的試算表工具
34. Microsoft PowerPoint : 簡報必備工具
35. Microsoft Word : 業界標準文書軟體
36. MilkyTracker : 離線時肯定好用的取樣 / 編曲工具！
37. Motrix : 免費速度快得下載器
38. Musescore 4 : 開源打譜軟體
39. Native Access : 官方的入庫管理工具
40. Numbers : 蘋果表格工具
41. OBS : 強大的開源螢幕錄影與直播軟體
42. Ollama : 在荒島時可用的離線 AI 工具，前提是電腦配置要好 … 想試試 Qwen
43. OpenBVE : 開源模擬駕駛遊戲，最近跳轉到 BVE6 真開心
44. Pages : 蘋果文件排版工具
45. Parallels Desktop : Windows 虛擬機，效能強大
46. Recordly : 錄影片時超萬用 (開源) 工具，但電腦卡頓
47. Pearcleaner : 乾淨卸載 App 的利器
48. Roblox : 我唯一玩的遊戲
49. Steinberg Library Manager : 管理 VST 音色庫路徑與授權的工具
50. Vorssaint : 開源強大的工具彙整工具，只能說太強大了
51. Vovious : 調音準很方便，媲美 Melodyne
52. VSCodium : 還是開源的文字編輯器好用
