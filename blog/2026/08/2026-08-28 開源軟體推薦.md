# macOS 開源軟體推薦

最近覺得真的要更跟大家推行開源軟體，真的很讚！所以今天來説説幾個我超愛的軟體～每個都很實用，如果能用 Linux 其實更好！

{/* truncate */}

## 01 | 瀏覽器別再依賴 Chrome 
這個真的建議別再用 Chrome 、 Edge 、 Safari 了，這些大公司都會偷偷搜集你的資料，而且廣告一堆
### 強烈建議使用：Brave 開源免費的瀏覽器還可以自動擋廣告！
不要再因為什麼蘋果生態系而使用 Safari 了！

## 02 | 音樂製作 + 音訊編輯
說真的我是不知道在看這篇文章的人會不會打譜啦～
但是拜託別自討苦吃用 Finale 、 Dorico，
### Musescore 真的就很夠用了！！！！
簡單打譜 + 高級聲音效果，甚至最近 4.7.5 可以直接匯出高級影片！

然後是 Audacity，不管是修音樂大小，去雜音，玩音效，其實 Audacity 就超夠用了，沒必要開編曲軟體。而且最近他們更新全新的 `Audacity 4` 介面變好看了！

## 03 傳輸任何東西的好工具
我猜你現在不是用 `Airdrop` 就是 `Google 的快速分享`，我來建議一定要裝 
### LocalSend ，不管是：檔案、資料夾、文字、甚至是剪貼簿
他都可以同步，跨平台包括：iOS、iPadOS、macOS、Windows、Android、Linux 他都沒問題
同步方式更厲害是使用 P2P 技術，讓資料免經過網路上也可以傳輸，缺點就是要在同個區域網內...

以上是我大推的開源工具，我相信你一定用得到，
### 這邊注意一下：Vorssaint
他有缺點是非跨平台，限定 macOS 使用，但是超級萬用！講幾個我喜歡的功能 
### 1. 關閉時結束
當我關閉視窗時會自動結束該軟體，像我現在打完 BLOG ，他會自動關閉 VSCodium
### 2. 反轉滑鼠捲動
他會自動反轉變得跟習慣的一樣，不過我是挺喜歡用 MacBook 內建的觸控板的哈哈哈哈
### 3. 暫存架
可以用快捷鍵啟用然後去放很多檔案進去，然後可以一次性移動，像我最近在整理電腦截圖跟照片就很方便～
### 4. 磁碟映像檔安裝器
安裝磁碟映像檔中的單一 App，並清理下載檔案，不用手動拖曳 APP (不過跟 Windows 比**簡單超多**)
### 5. 清潔模式 / 清理
鎖定鍵盤和螢幕以便清潔 / 清理快取和垃圾檔案•管理下載項目中的 WhatsApp 檔案
### 6.Homebrew / App 更新
讓 Homebrew 套件保持最新 / 尋找並安裝你的 App 更新
### 7. 指令列
這個夯爆了，直接完美替代 Raycast、Asyar！一個輸入欄位，找到並執行 App 的所有功能
### 8. 系統監視器

- CPU   
按間隔檢查處理器使用率與溫度

- GPU   
按間隔檢查圖形使用率與溫度

- 記憶體   
按間隔檢查記憶體使用量與壓力

- 網路   
按間隔檢查 **網路速度與用量**

- 磁碟    
按間隔檢查磁碟空間與活動

- 電源   
按間隔檢查電池、功耗與充電

- 風扇控制 `BETA`   
暫時讓所有風扇全速運轉，然後把控制權交還給Mac
