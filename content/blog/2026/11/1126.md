今天才知道原來 FSearch 要配參數才會好用


首先我參考了一下 [FSearch 官方搜尋語法文件](https://github.com/cboxdoerfer/fsearch/wiki/Search-syntax) 整理所有可用指令與參數規則。

### 1. 布林運算子與萬用字元


| 指令 / 符號             | 說明                    | 範例                            |
| --------------------- | --------------------- | ----------------------------- |
| `空格` 或 `AND` 或 `&&` | 同時符合前後兩個條件      | `video mp4` 或 `video AND mp4` |
| `OR` 或 `\|`         | 符合其中任一條件即可           | `jpg OR png`                  |
| `NOT` 或 `!`         | 排除後方指定的條件             | `!backup` 或 `mp4 NOT sample`  |
| `( )`               | 群組條件，決定優先順序           | `(cat OR dog) ext:jpg;png`    |
| `*`                 | 匹配零個或多個任意字元           | `*.pdf`、`2026*report`         |
| `?`                 | 匹配單一任意字元              | `k?ng`（可找到 king、kong）         |
| `" "` 與 `\`         | 雙引號代表字面搜尋，反斜線用於跳脫特殊符號 | `"my file (1).mp4"`           |


### 2. 修飾詞 (Modifiers)

修飾詞加在關鍵字或函式前方，用來改變比對範圍或規則，可連續串接（例如 `file:case:Test`）。
但老實說，這個我不常用。

| 指令                     | 說明                    | 範例                       |
| ---------------------- | --------------------- | ------------------------ |
| `case:` / `nocase:`    | 區分大小寫 / 忽略大小寫         | `case:README`            |
| `exact:`               | 完全符合整個檔案或資料夾名稱        | `exact:test`（不會找到 test1） |
| `file:` / `files:`     | 僅搜尋檔案                 | `file:project`           |
| `folder:` / `folders:` | 僅搜尋資料夾                | `folder:backup`          |
| `path:` / `nopath:`    | 比對完整路徑 / 僅比對檔名        | `path:Downloads/2026`    |
| `regex:` / `noregex:`  | 啟用 / 停用正規表達式（建議搭配雙引號） | `file:regex:".+\.mp4$"`  |

### 3. 篩選函式 (Functions)

函式用來指定檔案屬性（大小、時間、副檔名、層級等）。 

| 指令              | 說明                  | 範例                |
| --------------- | --------------------- | ---------------- |
| `ext:<清單>`                      | 指定副檔名，多組請用分號 `;` 分隔    | `ext:mp4;mkv;avi`                  |
| `size:<大小>`                     | 篩選檔案大小（用 `kb`、`mb`、`g`、`t`） | `size:>5mb`、`size:100mb..1gb`      |
| `dm:<日期>` 或 `datemodified:<日期>` | 篩選最後修改日期       | `dm:today`、`dm:lastweek`、`dm:2026` |
| `parent:<路徑>`                   | 搜尋指定資料夾底下的內容   | `parent:/home/user/Videos`         |
| `depth:<數字>` 或 `parents:<數字>`   | 篩選特定的資料夾深度層級                               | `depth:2`                          |
| `empty:`                        | 找出所有空資料夾                                   | `empty:`                           |
| `childcount:<數字>`               | 篩選子項目總數符合條件                           | `childcount:>10`                   |
| `childfilecount:<數字>`           | 篩選內部檔案數量符合條件                          | `childfilecount:0`                 |
| `childfoldercount:<數字>`         | 篩選內部子資料夾數量符合條件                         | `childfoldercount:>=5`             |
| `contenttype:<類型>`              | 依據 MIME 內容類型篩選                             | `contenttype:video`                |

### 4. 數值與日期比較符號

所有支援 `<num>`、`<size>` 與 `<date>` 的函式皆可搭配以下符號： 

- **比較運算子。** 支援 `<`（小於）、`>`（大於）、`<=`（小於等於）、`>=`（大於等於）與 `=`（等於）。
- **範圍區間 (`..`)。** 使用兩個點連接上下限，例如 `size:10mb..50mb` 或 `dm:2026-01-01..2026-06-30`。
- **內建日期常數。** `dm:` 可直接使用 `today`、`yesterday`、`thisweek`、`lastweek`、`thismonth`、`lastmonth`、`thisyear`、`lastyear` 等英文關鍵字。 


### 實用組合範例

最後整理了一些我常用得技巧：

- **清理大型影片檔。** `ext:mp4;mkv size:>500mb !path:Movies`（找出不在 Movies 資料夾內且大於 500 MB 的影片）。
- **尋找本週修改的文件。** `ext:pdf;docx;xlsx dm:thisweek`（找出本週更動過的常見辦公文件）。
- **排查空資料夾。** `empty: path:/home/user/Downloads`（列出下載資料夾內所有空的子目錄）。
