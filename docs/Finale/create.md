## 怎麼建立新專案？

<details>
<summary>首先開啟 Finale 之後，可透過上面的 Setup-Wizard 建立新專案</summary>

![alt text](./create/create-page.jpeg)
</details>


## 第一頁為選擇模板
<details>
<summary>在這邊請先看圖片後往下閱讀！</summary>

![alt text](./create/template.jpeg)
</details>
    不過建議養成好習慣是：
:::danger 注意！
<div className= "red-stroke-text">**不要使用模板**</div>
:::


- **直接**按 `Next` (或著`Enter`)

## 選擇樂器
<details>

<summary>接下來是選擇樂器！選擇要的樂器後按`Add`加入或著`Remove`移除</summary>

![alt text](create/add.jpeg)

</details>
- **繼續**按 `Next` (或著`Enter`)

## 樂譜資訊
<details>
<summary>這邊建議什麼都不要填，除非你怕有人拿這譜去販售 🤣🤣</summary>

![alt text](create/info.jpeg)
</details>
:::tip 名詞解釋
- Title: `標題`
- Subtitle: `次標題`
- Composer: `作曲家`
- Arranger: `編曲家`
- Lyricist: `填詞者`
- Copyright: `版權資訊`
:::

## 樂譜屬性

<details>
<summary>這邊建議什麼都不要改，之後再改啦！如果你有強迫症建議把預設小節數：`31` 改成 任何整數 </summary>

![alt text](create/31.jpeg)
</details>

看個人！ [^1]

> 然後建議讓 `樂譜速度` 顯示！

<details>
<summary>這樣隨時可以修改速度</summary>

![alt text](create/tempo.jpeg)
</details>
> 按 `Finish` (或著`Enter`) 完成建立樂譜！

## 快速新增五線譜

這樣皆算是快速設定，我是習慣直接建立空白五線譜
<details>
<summary>可以到上面選單 > File - New - Default Document</summary>

![alt text](create/new1.jpeg)
</details>
## 快捷鍵設定
#### 你會發現在上面我有設定快捷鍵 `⌘+N`！只要開好 Finale，直接按快捷鍵就好了超爽！
:::warning 注意
預設快捷鍵：`⌘+N` 是開啟`Setup-Wizard` 
:::
<details>
<summary>超爽設定！</summary>
- 步驟一：找到設定！

![alt text](create/findset.jpeg)

- 步驟二：修改Default New Operation為
`Default Document`
![alt text](create/change.jpeg)
</details>

- 下面記得按 Apply
