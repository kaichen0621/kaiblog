注音輸入法採智慧型設計，可讓您輕鬆輸入國字、詞組和句子 在注音鍵盤上滑動即可輸入數字、英文字母和標點符號 可在注音鍵盤上使用手勢輸入 可選擇以繁體中文或簡體中文輸出 可在注音和拼音鍵盤上混合輸入中英文 提供豐富多樣的表情符號
