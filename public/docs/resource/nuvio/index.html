最近因為原本用的追劇管道不太順暢，便開始尋找有沒有更彈性、介面簡潔且能跨裝置同步的解決方案。幾經摸索後，發現了 Nuvio 這款開源的播放軟體。

對於平常喜歡看日本動畫（特別是像《名偵探柯南》這種長篇作品）的人來說，搭配適當的套件設定，就能獲得相當不錯的觀影體驗。這篇文章就來整理一下實測下來的心得，以及從零開始的設定步驟，分享給有相同需求的朋友。

什麼是 Nuvio？#

簡單來說，Nuvio 是一個開源的媒體播放器與影音管理介面（核心架構與 Stremio 相似）。

特別需要說明的是：Nuvio 本身完全不儲存或提供任何影片檔案。它只是一個「空殼」或「播放器平台」，所有的海報封面、影片介紹、影片來源與字幕，都是透過安裝社群開發的 Addons（擴充外掛/插件） 連結進來的。

它的主要優點：#

  • 跨裝置同步：只要註冊並登入同一個 Nuvio 帳號，不論在 Android 手機、平板還是 Google TV / 電腦上，已安裝的套件與觀看進度都會自動同步。
  • 介面乾淨：沒有繁雜的廣告或強制推播。
  • 自由度高：可以根據個人喜好選擇不同的資料庫來源（例如一般影劇目錄或是動漫專用目錄）。

需要先說明的注意事項：#

  • 介面語言為英文：目前選單介面尚未支援繁體中文，但基本操作圖示都很直覺，不影響影片播放。
  • 串流速度取決於來源：播放是採用 P2P 邊下載邊緩衝的方式，因此觀看時需要挑選種子數（Seeds）較多的連結，或是挑選檔案大小適中的版本（例如 200MB~400MB），載入會快很多。

必備外掛（Manifest URLs）整理#

因為安裝套件需要輸入對應的 manifest.json 網址，這裡把最常用的幾個整理在一起，方便大家長按複製：

1. 核心影音來源（Torrentio）#

尋找串流連結最主要的來源，建議優先安裝：

https://torrentio.strem.fun/japanesefor/manifest.json

2. 目錄與海報資料庫（Catalog Addons）#

  • Cinemeta（官方基礎目錄）：最標準的影劇目錄，適合按傳統季度（Season 1, 2…）查看。
    https://v3-cinemeta.strem.io/manifest.json
  • Kitsu Anime（動漫專屬目錄）：專門為日本動漫設計的資料庫，特色是每一集幾乎都有專屬的精美劇照與英文/日文標題，資料非常豐富。
    https://anime-kitsu.strem.fun/manifest.json

3. 字幕套件（OpenSubtitles）#

自動搜尋與載入字幕：

https://opensubtitles-v3.strem.io/manifest.json

圖文步驟：從安裝到播放的設定流程#

第一步：安裝應用程式與註冊帳號#

  1. 下載 App：建議前往 Nuvio 的 GitHub 官方頁面下載最新版的 APK 檔案進行安裝（功能相對最完整）。
  2. 建立帳號：第一次開啟 App 時，建議先註冊一個 Nuvio 個人帳號並登入。這樣未來在電視或第二台裝置上就不用重新設定外掛。

第二步：安裝核心擴充套件（Addons）#

  1. 點擊右下角的 Profile（個人檔案）。
  2. 進入 Addons 選項。
  3. 點擊頂部的藍色按鈕 Install Addon。
  4. 將上述整理的 Manifest 網址逐一貼入並點擊確定完成安裝。

小小經驗談：如果同時安裝了 Cinemeta 與 Kitsu，搜尋時可以拿到最完整的資料。若遇到切換開關後畫面變空白，通常只是暫存未更新，只要把 App 從背景完全關閉再重開即可。

第三步：搜尋與選擇影片#

  1. 點擊下方的 Search（搜尋）。
  2. 輸入 Detective Conan 或 名探偵コナン。
  3. 點進想看的集數後，系統會列出 Torrentio 抓取到的串流連結。
  4. 選擇原則：挑選 👥 Seeds 數字較大 且 檔案大小較適中（例如 200MB~500MB）的連結點擊播放。

第四步：開啟中文字幕#

影片開始播放後，點擊播放器選單中的 CC（字幕圖示），選擇 Traditional Chinese（繁體中文） 即可開始欣賞日語原音配音與中文字幕。

使用心得總結#

Nuvio 剛接觸時可能會覺得需要設定外掛有些繁瑣，但只要把基本架構與 Manifest 網址處理好，後續的使用體驗其實非常順手。尤其是設定一次之後，家裡的 Google TV 登入就能直接接續觀看，省去了重複設定的麻煩。
