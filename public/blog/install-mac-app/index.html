Google 一下#

:::warning 先說方法好了 :

  1. 打開 Ternimal
  2. 輸入以下指令
sudo xattr -r -c 

    ※ -c 後面要有 `空白鍵一格`

  1. 直接把 要解鎖的應用程式 移動到終端機

  2. 當你看到：「sudo」正在嘗試以管理者身分執行指令。使用Touch ID 或輸入密碼來允許此項目。

  • 輸入密碼 / 指紋
  1. 試著打開軟體 :::
