什麼是合成器#

1）合成器是電子樂器：發聲不靠機械結構震動
電吉他不是合成器
2）沒有既定音色：
Delay: 最喜歡乒乓 Delay
FM 調變：夜訪吸血鬼開頭
不要被內建音色綁住
3） 合成器不是鍵盤樂器
吹管樂器也是合成器，Bass 踏板也是合成器

合成器的特色#

1）頻率寬廣：電子發聲不受限制
正弦波 很低到很高
2）角色多變：可模仿傳統樂器也可以自成一格
SuperSaw 音色
合成器取代 Bass
鋸齒波 + 低八度方波
Shape 成 Bass 放寬，加低頻 EQ
3）彈奏只是演奏的一半：演奏參數很重要
加入琶音器 Arpeggiator，齊奏 Unison
讓他自己走，演奏的是參數
4）發聲數可變：單發聲數 Mono vs 多發聲數 Poly vs 齊奏 Unison
單發聲數聲音來源：Vocal 管樂…
5）彎音與滑音：合成器可改變平滑音音高
6）表演輔助項：PitchBand、 ModWheel、 Aftertouch (新增 CutOFF) MONO Aftertouch 整台琴發生
Poly Aftertouch 單音可設定、Ribbon

什麼不是合成器？#

電鋼琴，自動伴奏機， 主控鍵盤 MIDI controller 不發聲

效果器 vs 合成器#

合成器自主發聲 ，效果器有輸入有輸出 手在空中 揮舞算是合成器嗎？ 不一定，模糊

類比 VS 數位#

數位優勢：可以模擬各種東西 類比合成器聲音本身在裡面

II. 模擬類比合成器 Analog Modelling Synthesizer#

把類比的 方便操控 數位操弄 輕量化

  • Nord
  • Roland
  • MicroKorg
  • YAMAHA
    用簡單波形作為音色素材，皆為 減法合成
  1. 找一個豐富的素材：supersaw
  2. 通過 低波濾波器 Low Pass Filter
    變比較溫暖
  3. 加一點 Resident ?
  4. 使用 LFO 自動濾波

合成器缺點：天生表現力不足#

須靠 合成音色 或者 加入效果

III. 取樣合成器 Sample-Based Synthesizer#

以錄製好的數位 Sample 為音色素材的合成器為 取樣合成器
為目前的主流
需要擬真 會使用一段 Sample 並將它循環播放

  • 後續結構能使用 減法合成
    還是可使用 filter

IV. 多引擎合成器 Multi-Engine Synthesizer#

旗艦機為主

  • YAMAHA
  • Nord
  • Korg
  • Roland

V. FM 數位合成器 Digital Synthesizer#

80 年代為主流
DX7 Finetune 古早味拔辣電鋼琴感覺
很多像是 Operator Envelope

擅長#

金屬感，敲擊感，Bell …
模擬：正弦波 + FM 變化
音色尖刺，可被指定到 envelop
變短變少，變成 Bass
變 2：1 時聽起來像是方波
（減法合成很難做到

VI. 波表合成器 Wavetable#

軟體居多，實體合成器較少：Vital
Table vs Sample
Mainstage + Swrum 合成器
Table 表，有很多單一複雜波形變成 一個 table
一次給 256 個 Sample ，有點像是一個懶人包

滑音 Glide#

指音高漸變
單發聲數重新觸發 Mono Retrigger
不管怎麼樣都會滑音
單發聲數連音 Mono Legato

齊奏 Unison#

音色虛擬增加
有 Detune 質感
用耳機聽會感覺變寬了

琶音器 Arpeggiator#

減法合成#

聲音產生的源頭提供比較完整的素材
一開始豐富，到後面越來越少，加法反之

減法合成像是製作雕刻，Filter 是頻率內容的雕刻工具

基本架構#

  • 振盪器 Oscillator
  1. 音高
  2. 質地
  • 濾波器 Filter
  • 擴大器 Amplifier

調變來源 Modulation Source (幫手)#

可做音高 / 質地變化

  • Envelop
  • LFO

波封 Envelope#

一次性的變化

  • Attack
  • Decay
  • Sustain
  • Release
    按住發生
    AD
    放開後
    SR
    A 從地板到最高點時間
    D 從最高點到 S 所需時間
    R 放開後從 S 高度回到地板所需時間
    S AD 之後的等待高度
