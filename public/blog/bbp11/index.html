這是我在「BlogBlog 同樂會 - 2026 年 11 月」的投稿文章。本月主題是「部落格文章（與他們的產地）」，由 資工小廢物 - JN 主持。如果你有自己的部落格，歡迎一起來參加！

部落格？那是什麼…
我朋友常常問我，部落格是什麼，用 Instagram 就好了啦～
我今天就是來分享的

在寫這篇文章之前，我想先特別感謝 JN，你開發的 IndiePing 真的超級厲害！！

他讓我知道，原來有人會認真的看文章，這個等之後再說好了

動機#

首先，讓我想開始寫一篇文章的原因是因為看到 wiwi 他不在YouTube了，原本是抱著想看更多編曲教學才開始訂閱 wiwi.blog 的哈哈哈～ 至於在我小的時候就很想要架設一個自己的網站，曾經走過過 Google site、WIX 甚至 WordPress
後來才慢慢認識 Hugo 跟 Docsuarus。 很好到現在還是記不得 Docsuarus 怎麼拼

老實說，我也沒有特別勤奮地去更新部落格，但就如同前面說的因為認識了不同的部落格朋友，才開始慢慢地每天寫一篇，所以你有時候看到我會很水，幾個字也算是一篇 。至於我投稿的動機完全是看主題好不好，主題如果不好寫我就跳過。像是一期一會原本要打算要投稿，但是 我根本不懂那是什麼意思，所以最後選擇放棄。

至於文章的靈感來源，來自於我每天上學可能發生的事情，或者今天有什麼特別的事之類的… 通常寫的時間是晚上9點到11點，寫一篇會花大概 30分鐘吧，短一點的10分鐘，長一點的有時候寫了兩天還沒寫完，原因其實蠻簡單的：有時候寫一寫就覺得不想寫了、所以到現在我一直拖一直拖，未完成的目前還有五篇 ，搞不好到了12月都還沒完成

工具、方法#

首先，我使用開源的 Zed 作為 Markdown 語法 的編輯器，它底層是使用 Rust 開發，速度會比 VSCodium 來得快，至於發佈網站的話，使用 Github 就可以了，我不會使用 AI 任何的文章，但是會使用AI來幫我修改網站的一些按鈕，畢竟我對那些沒有什麼概念，什麼 HTML、CSS、JS 之類的
