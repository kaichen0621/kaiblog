🚀 網站掛掉了#

為什麼會掛掉？

  1. Github 莫名被盜用
    • 我已經啟用 雙步驟認證 了，但還是被盜
  2. Github Action 強制停止！
    • 因為帳號被盜用，所以 Github Action 被強制停止，導致網站無法更新
  3. is-a.dev 域名被轉移！
    • 因為帳號被盜用，所以 is-a.dev 域名被轉移，導致網站無法訪問

{/* truncate */}

🔧 我要怎麼做？#

請求 Github 讓該帳號可以使用！

  • 已申請帳號被鎖定，申訴中

等待 admin 審核中…

❓ 到底發生什麼事？#

2026/04/23 下午3點左右，我收到了 Github 的 email，內容大概是說我的帳號被鎖定了，因為發現了異常登入，但是不是我本人操作的，所以我就申請申訴

結果不但沒收到回覆，反而收到了 Github 的信件，內容大概是說

“You’re receiving this email because we noticed unusual activity on your GitHub account…”

然後我就登入了我的 Github，發現我的帳號 Action 被鎖定了，然後我就申請申訴！
