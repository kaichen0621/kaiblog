國防考試重點

November 25, 2026 · 3 分鐘 · Kai
目錄
  • 是非題
  • 選擇題
  • 是非題 X10
  • 選擇題 X30

是非題#

  1. 安全是一種主觀感受 (P8)
  2. 「國家安全」的範疇極為廣泛，傳統以軍事作戰為核心的安全，概念也逐漸改變。 (P11)
  3. 「水資源及糧食危機」和「少子化與高齡化」 不是 非傳統安全威脅問題。(P18)
  4. 因應中共的統戰作為與三戰守法，國人必須積極一些持續生化全民對國防教育的認同 (P25、O)
  5. 國防部強調不用投筆，也能從戎，鼓勵青年學子加入國軍行列，且培養一技之長。 (P29、0)
  6. 代理人戰爭的目的是 間接地 打擊對手，但又不會引起全面戰爭 (P12)
  7. 傳統安全威脅的手段 多是以「政治閗旋」、「外交行為」或「戰爭軍事行動」等類型出現 (P13)
  8. 國防部施行14天新制教召，增加戰鬥教練課程時數。 (P38、0)
  9. 國防部持續在航太、船艦、資安上投入資源，近期亦積極參與無人載具的開發，形成國防資源的良性循環。 (P38、0)
  10. 然而，當前的恐怖勢力朝向成本低、效益高，且具隱蔽性與機動性的本土化。 (P19)

選擇題#

  1. 國家的組成條件包含：人民、領土、政府、主權 (P8)
  2. 國家的組成條件細項 (P8)
  3. 「國家安全」 在概念上則可以說是人民、領土、政府、主權免受到威脅 (P10、混淆題)
  4. 若國家屬於不安全狀態，除了人民、領土、政府、主權將會遭受影響外，國家利益與存續 將受到牽連 (P10)
  5. 受戰火肆虐國家的人民：生命能受到保障與延續或者恢復戰前生活 (P10)
  6. 弱勢國家的人民 包含 能夠健康的活下去、三餐能溫飽、一處遮風避雨之所 (P10、考 不包含 )
  7. 1）人民生活不受外力干涉與生存不受威脅、2）領土完整不受他國侵犯、3）政府功能獨立且運作正常、4）主權完整 (P11、混淆題)
  8. 新興的威脅類型稱為 「非傳統安全」 。 (P12)
  9. 代理人戰爭 指兩個強權國家不直接參戰。(P12)
  10. 國家安全的重心大多集中於 「軍事、政治與外交」 等領域 (P12、 考 錯誤 )
  11. 我國當前所面臨的傳統安全威脅，主要來自中共針對性的 軍事演習 、常態系的趨勢挑釁、發動武力犯台之威脅、 政治打壓 與外交爭奪 (P14、考 錯誤 )
  12. 非傳統安全具有跨國性、廣泛性、相互影響等特性。 (P16)
  13. 「預防戰爭」 是最積極也最有效的方式 (P22)
  14. 凝聚全民向心力，藉此可建立國家安全共識 (P23)
  15. 整合全民總理，秉持：「納動員於施政」、「寓戰備於經建」、「藏熟練與演訓」的精神
  16. 全民國防將更多元、更完美。包括「凝聚全民向心力」、「整合全民總力」及「鞏固全民新防」等 (P23、考 為非 )
  17. 興論戰：透過媒體炒作，製造政府與民間矛盾 (P25)
  18. 興論戰、心理戰、法律戰 (P25、考 為非 )
  19. 台灣將 9月3號 定為我國的「全民國防教育日」。 (P26)
  20. 全民國防教育實施的原則包括：學校教育、政府機關、社會教育、國防文物保護 (P27、學校到社會)
  21. 各軍種舉辦的暑期戰鬥營、寒假戰鬥營，在 太平島 上進行活動 (P28)
  22. 以色列 國防的重要實踐包括：「高額的國防預算」、「全民皆兵的政策」、「多元的精神教育」 (P30)
  23. 瑞士採取「 總體防禦戰略 」，全民一致展現強烈的抗體意志。 (P32)
  24. 新加坡政府對常備軍人有多項獎勵措施。 (P34)
  25. 新加坡於 1984年 提出「總體防衛構想」，其核心概念強調心理、社會、經濟、民事、軍事防衛。 (P34)
  26. 因蘇聯創飛彈的成功，讓美國倍感威脅。迫使美國政府制定 「國防教育法」 。 (P36)
  27. 美國紮實的國防投資占 世界第一，且持續研發新事科技與多樣化武器設備。 (P36)
  28. 政府推動自主性協助、防救災團體辦理防救災宣導、救助工作以及建立 韌性社區 ，積極推廣防災式的訓練 (P38)
  29. 全民國防 是我國國防的核心理念，包括「國防軍事領域」以及面對傳統與非傳統安全威脅的防衛能力。 (P39)
  30. 在國際援助方面，我國的醫療團、農耕團、救災團不斷在國際提供援助 (P38、考 為非 ex.聯合國 )
