媒體類#

對我來說，比起文字、圖片，我更喜歡影片跟音樂耶…

影片 - 或許有超多集的飢餓遊戲 + 可能好和弦的教學影片應該就夠了吧！當然我會先把檔案稍微壓縮過，然後畫質我是認為 360 P 就夠看了

音樂 - 當然是一些古典音樂呀，我可能會放浪漫時期或者現代的吧，像是拉赫曼尼諾夫、舒伯特、華格納（？….等

至於流行音樂的話，就是五月天、周杰倫、林俊傑三位吧

啊對了，一定會放的就是 五月天線上跨年演唱會，雖然說畫面比較精緻，但是檔案真的太大了，而且我是比較喜歡用聽的，因為 阿信說話真的真的很溫柔、很好聽

資料類#

說到簡報，我好期待 WiNote 上線哦天呀，因為看起來就真的很好用呀 ~

遊戲類#

軟體類等等說，因為內容超多（？

遊戲目前我只玩 Roblox ，但是在荒島根本沒有網路，所有不能玩，那可能頂多就是體驗一下在日本開電車的感覺吧，會不會覺得我很奇怪欸哇啊哈哈哈哈哈哈，這邊推薦 BVE 6 是完全開源的哦 ~

軟體類#

一個一個說吧，首先當然是開源的最好，然後別問我為什麼但是我喜歡的跟你們喜歡的可能不太一樣

  1. After Effect : 製作特效軟體
  2. Media Encoder 2026 : 用 Adobe 的軟體匯出好像得用它
  3. Affinity : 製作縮圖常用
  4. Anytype : 超好用開源筆記軟體，載入速度極快、同步方便！
  5. Audacity : 免費開源超好用的音訊編輯器
  6. Cubase 15 : 主要的編曲軟體，教學資源不錯
  7. DaVinci Resolve 21 : 找不到比他更好的調色與剪輯軟體了
  8. Finale 27 : 停止提供更新了，最近沒什麼在用
  9. GIMP : 曾老師教學的圖邊軟體，超好用！
  10. HandBrake : 處理影片畫質開源好幫手！
  11. IINA : 開源萬能播放器，Mac 必裝
  12. Kdenlive : 開源輕量剪輯軟體
  13. Keka : 超好用壓縮工具！RAR 打得開～
  14. Keynote : 蘋果簡報工具
  15. Krita : 畫畫工具
  16. Logic Pro : 蘋果自家 DAW，想刪除了！ (錄音老師推薦不要刪)
  17. Musescore 4 : 開源打譜軟體
  18. Numbers : 蘋果表格工具
  19. OBS : 強大的開源螢幕錄影與直播軟體
  20. Ollama : 在荒島時可用的離線 AI 工具，前提是電腦配置要好 … 想試試 Qwen，最後跑不動
  21. Pages : 蘋果文件排版工具
  22. Parallels Desktop : Windows 虛擬機，效能強大
  23. Pearcleaner : 乾淨卸載 App 的利器
  24. Vorssaint : 開源強大的工具彙整工具，只能說太強大了
  25. VSCodium : 還是開源的文字編輯器好用

個人作品#

應該是沒什麼，但是如果在荒島，我應該會用 musescore 做音樂吧
