01. 開頭#

開場氣勢佳，開場後張力強，但是關鍵在於：有些音色會有 Delay / Reverb ，所以 當主歌時會有殘響時

解決辦法：

  1. 將拍子提前結束
  2. 將合成器的 Tape Echo 關小
  3. 使用 Read / Write 靜音 (不推薦)

原始人 處理#

內建的 OmmiVocal 雖然可以輸入文字來發聲，但是效果不好，很假

建議屎用

  1. Kontakt Shevannai (超好用)
  2. VoiceWar (備用)

🔐 付費解鎖！#

02. 大提琴#

  1. 使用 Velocity 調整力度
  2. 用 Modulation 讓大提琴活起來
  3. 聲音壓低，不要太大聲
