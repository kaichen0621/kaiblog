影片 1: Mac 新手教學，從 Windows 老手到 Mac 的技巧分享(papaya)#

這部影片旨在幫助 Windows 用戶順利轉移到 Mac 平台，提供了許多從基礎到進階的操作指引。

一、軟體安裝與管理#

  • App Store 安裝流程：

    如同 iPhone 使用 App Store，影片詳細展示了如何在 Mac App Store 搜尋、下載與安裝應用程式。安裝後，這些應用程式會自動出現在 Launchpad 中，這是一個類似 iPad 主畫面的應用程式總覽介面，方便用戶快速開啟。

  • 網頁下載與安裝：

    對於非 App Store 的應用程式，影片說明了從網頁下載 .dmg 或其他安裝檔後，通常只需將應用程式圖示拖曳到「應用程式」資料夾即可完成安裝，非常直觀。

  • Dock 的應用：

    螢幕底部的 Dock 類似 Windows 的工作列，用於存放常用應用程式。影片示範了如何將應用程式拖入或拖出 Dock 進行自訂，讓常用工具隨手可得。

  • 應用程式移除：

    Mac 移除應用程式比 Windows 簡單許多。影片中示範了透過 Finder（Mac 的檔案總管），直接將「應用程式」資料夾中的程式圖示拖曳到垃圾桶即可完成解除安裝，無須複雜的移除程式。

二、滑鼠與觸控板操作#

  • 巧控滑鼠 (Magic Mouse) 手勢：

    這款獨特的滑鼠透過表面感應提供豐富的手勢操作，影片中介紹了向上/向下捲動頁面，以及左右滑動切換網頁的實用功能，讓瀏覽體驗更流暢。

  • 右鍵點擊的實現：

    Mac 預設可能沒有獨立的右鍵。影片提供了兩種方法：一是按住 Control 鍵再點擊滑鼠（或觸控板），二是到「系統偏好設定」中啟用滑鼠或觸控板的右鍵點擊功能，方便用戶存取上下文選單。

  • 滑鼠追蹤速度調整：

    在「系統偏好設定」中，用戶可以依據個人習慣調整游標的移動速度與靈敏度，找到最舒適的操作手感。

  • 觸控板多指手勢：

    Mac 觸控板是其一大特色。影片深入介紹了各種多指手勢的應用，例如雙指捲動、三指或四指滑動切換桌面/應用程式等，極大地提升了操作效率。

三、系統偏好設定重點#

  • 桌面背景自訂：

    影片示範了如何輕鬆更改 Mac 的桌面背景，個性化您的工作空間。

  • 字體大小調整：

    在系統偏好設定中，用戶可以調整應用程式介面中的字體大小，以提高閱讀舒適度。

  • 時光機 (Time Machine) 自動備份：

    這是 Mac 獨有的強大備份工具。影片詳細解釋了如何連接外接硬碟，設定時光機進行自動數據備份，並在需要時將系統恢復到之前的狀態，確保數據安全。

四、鍵盤差異與快捷鍵#

  • Mac 獨有按鍵：

    介紹了 Mac 鍵盤上的 Command (⌘) 和 Option (⌥) 鍵，這兩個鍵在 Mac 操作中扮演著核心角色。

  • 快捷鍵對應關係：

    影片特別指出，Windows 中的 Ctrl 鍵功能在 Mac 上通常對應 Command (⌘)，而 Windows 中的 Alt 鍵功能則對應 Mac 上的 Option (⌥)，這對於從 Windows 轉移過來的用戶來說是重要的適應點。

  • 常用快捷鍵：

    示範了基本的複製（Command + C）和貼上（Command + V）等操作，並補充了 Fn + Delete 用於刪除游標右側文字的功能。

五、視窗管理#

  • 視窗控制按鈕：

    Mac 視窗的關閉（紅）、最小化（黃）、最大化/全螢幕（綠）按鈕位於左上角，與 Windows 不同。

  • 應用程式選單列：

    Mac 的選單列固定在螢幕最上方，內容會根據當前活躍的應用程式而變化，這是一個 Mac 獨特的設計。

  • Apple 選單：

    位於螢幕左上角的 Apple 圖示選單，提供了系統級指令，如「睡眠」、「重新啟動」、「關機」和重要的強制結束功能。

  • 強制結束應用程式：

    當應用程式無響應時，影片教授了使用 Option + Command + Escape 的快捷鍵強制關閉它們。

  • 關閉視窗與結束應用程式的區別：

    這是 Mac 新手常遇到的混淆點。點擊紅色關閉按鈕或使用 Command + W 僅關閉視窗，應用程式可能仍在後台運行（Dock 上會顯示一個小黑點）。影片強調，要完全結束應用程式，必須使用 Command + Q。

  • 視窗最大化與全螢幕：

    點擊綠色按鈕通常會進入全螢幕模式。影片補充了按住 Option 鍵再點擊綠色按鈕，可以在不進入全螢幕的情況下最大化視窗。

  • 分割顯示 (Split View)：

    透過將滑鼠懸停在綠色按鈕上，可以選擇將兩個應用程式視窗並排顯示，提升多工效率。

  • 最小化與隱藏視窗：

    點擊黃色按鈕或使用 Command + M 將視窗最小化到 Dock 右側。使用 Command + H 則可隱藏視窗，不將其放入 Dock，保持桌面整潔。

  • 應用程式切換：

    使用 Command + Tab 可以快速循環切換所有已開啟的應用程式。

  • 指揮中心 (Mission Control)：

    影片介紹了透過巧控滑鼠兩指輕點或觸控板三指向上滑動來啟用指揮中心，以一覽所有開啟的視窗、桌面和全螢幕應用程式，方便快速切換和管理。

六、檔案與資料夾管理 (Finder)#

  • Finder 檔案檢視方式：

    影片展示了 Finder 的四種檢視模式：圖示、列表、直欄和圖庫，並提供了對應的快捷鍵（Command + 1、2、3、4），讓用戶可以根據需求選擇最佳的檔案瀏覽方式。

  • 快速查看 (Quick Look)：

    選取檔案後按下空白鍵即可快速預覽各種檔案（圖像、影片、文件等），無需開啟應用程式，極大提升效率。

  • 路徑列 (Path Bar)：

    影片說明了如何在 Finder 視窗底部啟用路徑列，顯示當前檔案或資料夾的完整路徑，方便用戶了解其位置並快速導航。

  • 檔案操作：

    涵蓋了常用的建立新資料夾、重新命名檔案、透過右鍵選單查看檔案資訊等基本操作。

檔案移動與複製的差異：#

Mac 沒有直接的「剪下」功能。影片解釋了複製是 Command + C，貼上是 Command + V；而要「移動」檔案（等同於 Windows 的剪下貼上），則是先複製（Command + C），然後在目標位置使用 Command + Option + V。

  • 刪除檔案：

    使用 Command + Delete 即可將檔案移至垃圾桶。

  • 我的最愛與標籤：

    影片建議將常用資料夾拖曳到 Finder 側邊欄的「我的最愛」中快速存取。同時，也介紹了為檔案添加顏色標籤的功能，方便在 Finder 中進行組織和快速篩選。

七、實用提示與技巧#

  • 內建字典查詢：

    選取文字後按下 Ctrl + Command + D，即可快速開啟內建字典查詢單詞解釋。

  • 表情符號選擇器：

    使用 Ctrl + Command + 空白鍵即可呼叫表情符號和特殊字元面板，方便輸入。

螢幕截圖與錄影：#

Shift + Command + 3：擷取整個螢幕。

Shift + Command + 4：擷取選定的矩形區域。

Shift + Command + 5：開啟完整的螢幕截圖和錄影工具列，提供更多選項，包括錄製螢幕。

  • Spotlight 搜尋：

    透過 Command + 空白鍵啟用 Spotlight，這不僅是一個強大的檔案和應用程式搜尋工具，還可以執行簡單的計算、查詢貨幣匯率和單位轉換，功能非常全面。

影片 2: Mac 技巧分享：10 個設定與操作，讓你的 Mac 更好用！(Apple99)#

這部影片聚焦於 10 個 Mac 設定與技巧，旨在提升用戶的日常使用體驗。

一、滑鼠與觸控板設定#

  • 追蹤速度調整：

    影片強調在「觸控板」設定中，將追蹤速度調整到一個舒適的區間（例如第二格），讓游標移動更符合個人直覺。

  • 輕點來按一下 (Tap to Click)：

    在「點按」設定中啟用此功能後，用戶只需輕觸觸控板即可完成點擊，無需實際按下，減少手部疲勞。

二、電池百分比顯示#

影片示範了如何在「控制中心」設定中啟用「顯示百分比」，讓電池剩餘電量直觀地顯示在選單列上，方便隨時掌握電量狀況。

三、Dock 自訂#

  • 移除應用程式圖示：

    透過將 Dock 左側（應用程式區域）不需要的圖示向上拖曳，直到出現「移除」字樣即可移除。

  • 新增應用程式圖示：

    從「Launchpad」或「應用程式」資料夾中，將所需的應用程式圖示拖曳到 Dock 的應用程式區域，調整位置即可。

  • 隱藏最近應用程式：

    在「桌面與 Dock」設定中，關閉「在 Dock 中顯示建議與最近使用的應用程式」，可以讓 Dock 保持更簡潔。

  • 新增檔案/資料夾捷徑：

    影片強調可以將常用的檔案或資料夾從 Finder 直接拖曳到 Dock 的右側（垃圾桶旁邊），建立快捷方式以便快速存取。

四、放大滑鼠指標#

在「輔助使用」設定中，透過「顯示器」下的「指標」選項，可以放大滑鼠指標的大小，並更改其外框和填充顏色，這對於視力不佳或需要更大指標的用戶非常有用。

五、停用「點擊桌面以顯示桌面」#

這個設定在「桌面與 Dock」的「幕前調度」部分。關閉「點擊背景圖片以顯示桌面項目」可以避免點擊桌面時，所有開啟的視窗自動移開，保持當前工作視窗的穩定性。

六、三指拖移#

在「輔助使用」設定中，「指標控制」下的「觸控板選項」中啟用「三指拖移」。這允許用戶使用三指在觸控板上拖動視窗或選擇文字，而無需按下觸控板，提高了便利性。

七、桌面與螢幕保護程式#

如果您的 macOS 版本是 Sonoma 或更新，影片建議在「螢幕保護程式」設定中選擇動態桌面和螢幕保護程式，例如「風景」系列，並啟用「顯示為背景圖片」，實現桌面與螢幕保護程式的無縫切換。

八、熱點 (Hot Corners)#

在「桌面與 Dock」設定中，找到「熱點」選項。影片建議將螢幕的各個角落設定為特定動作，例如：

  • 右下角設定為「桌面」：快速顯示桌面。
  • 左下角設定為「啟動螢幕保護程式」：快速鎖定螢幕。

這種功能可以與三指拖移結合使用，例如快速將檔案拖曳到桌面，然後再拖回應用程式。

九、快速鎖定螢幕#

結合熱點的應用，影片建議在「鎖定螢幕」設定中啟用螢幕保護程式啟動後需要密碼的功能。這樣，透過啟動螢幕保護程式的熱點，就可以快速鎖定螢幕，保護隱私。

十、應用程式 Exposé#

在「觸控板」設定的「更多手勢」中，設定一個多指（例如四指）向下輕掃的手勢來啟動「應用程式 Exposé」。這個手勢會顯示當前活躍應用程式的所有開啟視窗，方便在同一應用程式的多個視窗之間快速切換。

影片 3: MAC教學！9個進階技巧，讓你的 MAC 更好用，工作更有效率！(AppleFans)#

這部影片提供了九個進階技巧，旨在優化 Mac 的使用體驗並提高工作效率。

一、增強的觸控板拖曳#

  • 拖移鎖定 (Drag Lock)：

    影片詳細介紹了如何在「輔助使用」設定中啟用「拖移鎖定」。啟用後，只需單指輕點並拖曳項目（如視窗或檔案），即使手指離開觸控板，拖曳狀態也會維持，直到再次輕點。這對於觸控板空間有限或不喜歡長時間按壓的用戶非常實用。

  • 三指拖移：

    影片也提到了三指拖移選項，但主講者更偏好單指拖曳，強調選擇最適合自己的方法。

二、熱點 (Hot Corners) 的進階應用#

影片再次提及熱點的設定，並建議配合 Control 鍵使用，例如將滑鼠移到角落並同時按住 Control 鍵才觸發動作（例如顯示桌面、開啟備忘錄），避免誤觸。

還提到了使用功能鍵與「Q」的快捷鍵來快速開啟備忘錄。

三、多個桌面 (Multiple Desktops)#

影片深入探討了 macOS 的多桌面功能，這對於組織不同工作任務非常有用。

  • 桌面組織：

    可以為不同的桌面設定不同的背景圖片，甚至將特定應用程式分配到固定的桌面，例如一個桌面專門用於工作，另一個用於娛樂。

  • 桌面切換：

    透過 Control 鍵 + 左右方向鍵或觸控板上的四指左右滑動，可以流暢地在不同桌面之間切換。

四、Finder 自訂#

  • 側邊欄最佳化：

    影片建議將常用的資料夾（如「文件」、「下載」、「圖片」）拖曳到 Finder 側邊欄，移除不常用的項目，讓導航更高效。

  • 工具列自訂：

    透過在 Finder 工具列上右鍵點擊，可以添加或移除常用的功能按鈕，例如 AirDrop、新增資料夾等，打造個性化的工作流程。

  • 顯示路徑列 (Path Bar)：

    影片建議在 Finder 視窗底部啟用「顯示路徑列」，這會清楚顯示當前檔案或資料夾的完整路徑，方便用戶了解層級關係。

五、進階 Finder 技巧#

  • 預設開啟資料夾：

    影片示範了如何設定 Finder 在開啟時預設顯示特定資料夾（例如「文件」），而非預設的「最近項目」。

  • 設定預設應用程式：

    用戶可以指定某種檔案類型預設由哪個應用程式開啟，例如所有 .txt 檔案都用特定的文字編輯器開啟。

  • 資料夾背景自訂：

    影片還展示了為 Finder 資料夾更改背景顏色或添加自訂圖片的個性化選項。

六、快速檢查總檔案大小#

這是一個非常實用的技巧：選取多個檔案後，右鍵點擊並按住 Option 鍵，上下文選單中的「顯示簡介」會變成「顯示摘要資訊」，點擊後即可查看這些檔案的總大小，無需逐一查看。

七、展開所有子資料夾#

在 Finder 的列表檢視中，當一個資料夾下有多個子資料夾時，按住 Option 鍵並點擊資料夾旁的向右箭頭圖示，即可一次性展開該資料夾下的所有子資料夾，方便快速瀏覽。

八、輕鬆複製檔案#

影片提供了一個比複製貼上更快的複製方法：按住 Option 鍵並將檔案拖曳到新的位置，即可立即創建該檔案的副本。

九、螢幕放大與輔助功能#

  • 螢幕局部放大：

    影片示範了使用 Control 鍵和觸控板上的兩指捲動（或滑鼠滾輪），可以對螢幕的特定部分進行放大，方便查看細節。

  • 懸停文字 (Hover Text)：

    開啟此功能後，按住 Command 鍵並將滑鼠懸停在任何文字上方，會彈出一個放大顯示的文字框，對於閱讀小字或需要放大文字的用戶很有幫助。

  • 浮動面板 (Floating Panel)：

    在訊息或 Pages 等應用程式中，此功能提供了一個更大的面板來顯示您正在輸入的文字。

十、將您的 Mac 變成 Wi-Fi 熱點#

如果您的 Mac 透過乙太網路連接到網際網路，影片詳細講解了如何在「系統設定」中的「一般」>「共享」>「網際網路共享」中，將 Mac 變成無線熱點，與 iPhone、iPad 等其他設備共享網路連接。

影片 4: 9 個 Mac 隱藏功能，讓你用 Mac 效率更高！（Papaya)#

這部影片揭示了 Mac 上許多鮮為人知但極其實用的「隱藏」功能，旨在大幅提升用戶的日常效率。

一、Dock 自訂與效率#

  • 拖曳檔案到 Dock 應用程式：

    影片示範了直接將檔案拖曳到 Dock 上的應用程式圖示上，可以快速用該應用程式開啟檔案。

  • 調整 Dock 高度：

    透過拖曳 Dock 上方的小分隔線，可以快速調整 Dock 的整體高度。

  • Dock 側邊擺放：

    按住 Shift 鍵並拖曳 Dock，可以將其從底部移動到螢幕的左側。

  • 隱藏 Dock：

    影片建議在 Dock 上右鍵點擊選擇「隱藏 Dock」，以獲得更大的螢幕空間。

  • 搭配快捷鍵使用隱藏 Dock：

    當 Dock 隱藏時，仍可透過 Command + Tab 切換應用程式，或透過 Command + 空白鍵開啟 Spotlight 啟動應用程式，完全不影響效率。

二、Spotlight 的進階應用#

  • 快速開啟應用程式/檔案：

    重申 Spotlight (Command + 空白鍵) 作為應用程式啟動器和檔案搜尋工具的強大功能。

  • 開啟檔案所在資料夾：

    在 Spotlight 搜尋結果中選中一個檔案後，按下 Command + R，即可直接開啟該檔案所在的資料夾，非常方便。

  • 精準搜尋語法：

    影片介紹了使用 kind: 來指定搜尋檔案類型（例如 kind:pdf），以及 date: 來篩選日期範圍，讓搜尋更精準。

  • Spotlight 計算與轉換：

    展示了 Spotlight 可以直接進行簡單的數學計算和貨幣轉換，無需額外開啟計算機或轉換工具。

  • 移除選單列 Spotlight 圖示：

    按住 Command 鍵並拖曳選單列上的 Spotlight 圖示，即可將其移除，讓選單列更簡潔。

三、選單列操作#

  • 重新排列圖示：

    按住 Command 鍵並拖曳選單列上的圖示，可以自由地重新排列它們的順序。

  • 新增常用功能：

    將常用的系統功能（如亮度、音量控制）拖曳到選單列，以便快速調整。

四、音量與亮度控制#

  • 細微調整：

    影片示範了按住 Shift 鍵再調整音量，可以聽到細微的音量變化。而按住 Shift + Option 鍵再調整音量或亮度，可以進行更精準的微調。

五、專注模式與顯示管理#

  • 快速啟用專注模式：

    按住 Option 鍵並點擊選單列上的時鐘圖示，即可快速啟用或停用專注模式，避免打擾。

  • 延伸顯示至 iPad：

    透過專注模式設定中的「鏡像」按鈕，可以將 Mac 的顯示延伸到 iPad，將 iPad 作為第二螢幕。

  • 通用控制 (Universal Control)：

    如果您的設備支援，影片展示了「通用控制」功能，讓您可以使用 Mac 的鍵盤和滑鼠無縫地操作 iPad，甚至在 Mac 和 iPad 之間直接複製貼上文字或檔案，實現極高的跨設備協同效率。

六、螢幕截圖技巧增強#

  • 移動選取區域：

    在螢幕截圖選取區域時（使用 Shift + Command + 4），按住空白鍵可以移動整個選取區域，方便精確定位。

  • 單獨視窗截圖：

    啟動截圖工具後，按下空白鍵，游標會變成相機圖示，點擊任何視窗即可單獨截圖該視窗。

  • 截圖工具列：

    重申 Shift + Command + 5 可以開啟完整的截圖和錄影工具列，提供更多截圖模式和錄影選項。

七、快速查看 (Quick Look) 的新功能#

  • 直接從圖像複製文字：

    影片驚豔地展示了在 Finder 中選取圖像後，按下空白鍵啟動 Quick Look，現在可以直接從圖像中選取並複製文字，無需任何 OCR 軟體，這對於從圖片中提取資訊極為便利。

  • 貼上不帶格式的文字：

    使用 Shift + Option + Command + V 貼上文字，可以清除所有格式，只保留純文字，這在處理從網頁或其他應用程式複製的內容時非常有用。

八、文字輸入與聯絡人技巧#

  • 表情符號面板：

    再次提及 Control + Command + 空白鍵開啟表情符號面板。

  • 文字取代：

    在系統設定中設定文字取代功能，可以將常用但較長的單詞或短語設定為簡短的快捷鍵，例如輸入「eml」自動變成「我的電子郵件地址」，大幅提高輸入效率。

  • 從聯絡人列印信封：

    影片示範了在「聯絡人」應用程式中選取聯絡人後，使用 Command + P 即可直接列印包含該聯絡人地址的信封。

九、視窗與文件管理#

  • 分割顯示：

    利用視窗左上角的綠色按鈕啟用分割顯示，方便並排工作。

  • 將分割視圖轉換為新桌面：

    在分割視圖模式下，使用觸控板三指向上滑動，可以將此分割視圖移到一個獨立的「桌面」空間。

  • 多個桌面：

    影片強調建立多個桌面來組織不同應用程式的重要性。

  • 在桌面間切換：

    使用觸控板三指左右滑動可以在不同桌面間快速切換。

  • 顯示「另存為…」選項：

    有些應用程式預設隱藏了「另存為…」選項。影片提示，在「檔案」選單中按住 Option 鍵，即可讓「儲存」變成「另存為…」。

  • 文件匯出 PDF：

    在 Pages 和 Keynote 等應用程式中，可以透過「輸出」功能將文件直接另存為 PDF。

  • 用 iPhone 掃描文件到 Mac：

    在 Finder 中右鍵點擊，可以選擇從 iPhone 掃描紙本文件，並直接將其轉化為 PDF 檔案傳輸到 Mac。

十、預覽 (Preview) 應用程式的強大功能#

  • 快速預覽 PDF：

    按下空白鍵即可快速預覽 PDF 檔案。

  • 合併 PDF 檔案：

    將多個 PDF 檔案直接拖曳到一個已開啟的預覽視窗左側邊欄，即可輕鬆合併它們。

  • 重新排列/提取 PDF 頁面：

    在預覽的側邊欄中，可以拖曳 PDF 頁面縮圖來重新排列順序，或將單個頁面縮圖拖出視窗來提取為獨立的 PDF 檔案。

  • PDF 註解：

    預覽提供了強大的註解工具，如紅筆、文字標註等。

  • iPhone 簽名文件：

    影片展示了如何在預覽中簽署文件時，使用 iPhone 作為觸控板來手寫簽名。

  • 圖像編輯：

    預覽不僅能看圖，還能進行基本的圖像編輯，包括裁剪、調整大小、調整亮度與色彩，甚至驚豔的圖像背景移除功能。

  • 影片剪裁：

    在預覽中開啟影片後，透過拖曳黃色邊界即可快速裁剪影片長度。

十一、瀏覽器快捷方式#

  • 快速進入網址列：

    使用 Command + L 可以快速將游標定位到瀏覽器的網址列。

  • 新分頁/關閉分頁/重新開啟分頁：

    分別使用 Command + T 開啟新分頁，Command + W 關閉當前分頁，以及 Shift + Command + T 重新開啟最近關閉的分頁。

  • YouTube 子母畫面：

    影片展示了在 YouTube 影片上雙擊右鍵，即可開啟子母畫面功能，讓影片可以在小視窗中繼續播放，同時進行其他操作。

  • 快速存取備忘錄：

    將游標移動到螢幕左下角，可以快速呼叫 Mac 內建的備忘錄應用程式（這需要配合熱點功能設置）。

十二、網站圖示到 Dock#

  • 建立網站捷徑：

    可以直接將瀏覽器網址列中的「地球」圖示拖曳到桌面，建立網站捷徑。

  • 自訂網站圖示：

    影片展示了進階技巧，可以從網路複製一個網站的 Logo 圖像，然後透過 Command + I 開啟捷徑的「簡介」面板，將 Logo 貼到圖示位置進行自訂。

  • 將捷徑拖曳到 Dock：

    最後將自訂好的網站捷徑拖曳到 Dock，即可快速開啟網站。

  • 瀏覽器內建功能：

    影片補充說明，Chrome 或 Edge 等瀏覽器現在通常內建了將網站轉換為應用程式的功能，步驟更簡便。

十三、取得資訊面板 (Command + I)#

  • 查看詳細資訊：

    對於選定的檔案，使用 Command + I 可以開啟「簡介」面板，查看其詳細資訊，如檔案大小、圖像尺寸、影片長度等。

  • 查看多個檔案總大小：

    這是一個隱藏技巧：選取多個檔案後，按下 Option + Command + I，即可顯示所有選定檔案的總大小，這比逐一查看更有效率。

  • 更改預設開啟應用程式：

    在「簡介」面板中，可以為特定檔案類型設定預設開啟的應用程式，並選擇「全部更改」應用於所有同類型檔案。

  • 設定為範本 (Stationery pad)：

    勾選「簡介」面板中的「範本」選項，當您開啟該檔案時，系統會自動創建一個副本，保持原始檔案不被修改，非常適合用於模板文件。
