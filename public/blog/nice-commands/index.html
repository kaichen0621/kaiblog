好用指令#

今天分享一些我常用的特殊指令

  • 轉換簡體 TO 繁體

    opencc -i input.srt -o output.srt -c s2twp.json

  • 啟用 Whisper 轉錄

    /Users/kai/Desktop/AI\ 字幕/start_ai.command ; exit;

  • FFMPEG 轉換MP4 TO MP3影片

    ffmpeg -i input.mp4 -q:a 0 output.mp3

  • FFMPEG 轉換 MOV TO MP4影片

    ffmpeg -i input.mov -c copy output.mp4

  • YT-DLP 下載 MP3

     yt-dlp -x --audio-format mp3 --audio-quality 0 "XXXXXXXX"

  • YT-DLP 下載 MP4

    yt-dlp -f "bestvideo[height<=720]+bestaudio/best" "XXXXXX"
