這是我在 Mac 上的軟體清單#

  1. Addictive Drums 2 Demo : 好用鼓音源，五月天用
  2. Addictive Keys Demo : 好用鋼琴音源，我覺得超好聽
  3. Affinity : 製作縮圖常用
  4. ArtCraft Launcher : 超猛啟動器，直接升級 Adobe Git.
  5. Arutira Center : 我不需要的軟體中心…
  6. Audacity 4 : 免費開源超好用的音訊編輯器
  7. Blip : 傳檔案神器，別被 Apple 生態圈綁架
  8. Brave Origin : 超好用的乾淨瀏覽器！只佔 433.8 MB
  9. ClipGrab : 下載任何影片超好用！包含 B 站之類的
  10. Cubase 15 : 主要的編曲軟體，教學資源不錯
  11. DaVinci Resolve 21 : 找不到比他更好的調色與剪輯軟體了
  12. Discord : 聊天與語音頻道首選
  13. Dorico 6 : 最近想刪除的打譜軟體，超級難用，還是喜歡 musescore
  14. EffectCraft : AE 開源替代品
  15. FilmCraft : PR 開源替代品
  16. Finale 27 : 停止提供更新了，最近沒什麼在用，感覺到 macOS 29 就不能用了
  17. Groove Agent SE : Cubase 內建的鼓機
  18. HALion Sonic : Cubase 內建音源，電量低
  19. HandBrake : 處理影片畫質開源好幫手！
  20. IINA : 開源萬能播放器，Mac 必裝
  21. iZotope RX 12 : 處理人聲超級好用的工具，最近砸到第12版了
  22. Keka : 超好用壓縮工具！RAR 打得開～
  23. Keynote : 蘋果簡報工具
  24. Kontakt 8 : 強大的採樣音源主機
  25. Kontakt Library Manager : 介面簡潔好用的管理音色工具
  26. Line : 必要但笨重的通訊軟體
  27. Logic Pro : 蘋果自家 DAW，想刪除了！ (錄音老師推薦不要刪)，最近推出：ProWaves
  28. Microsoft Excel : 試算表工具，好想刪除！
  29. Microsoft PowerPoint : 簡報工具，好想刪除！
  30. Microsoft Word : 文書軟體，好想刪除！
  31. Motrix : 免費速度快得下載器，2.0 超級好用
  32. Musescore 4 : 開源打譜軟體，簡單好用
  33. Native Access : Kontakt 官方的入庫管理工具
  34. Numbers : 蘋果表格工具
  35. OBS : 強大的開源螢幕錄影與直播軟體
  36. Obsidian : 確定從 Anytype 跳槽到這個了！
  37. OpenScreen : 錄影騎士還可以，但是常當機
  38. Pages : 蘋果文件排版工具
  39. Parallels Desktop : Windows 虛擬機，效能強大
  40. Pearcleaner : 乾淨卸載 App 的利器
  41. PdfCraft : AP 開源替代品
  42. PlugPane : 插件整理工具
  43. Roblox : 我唯一玩的遊戲
  44. RustDesk : 遠端桌面工具
  45. SoundCraft : 這個不知道能不能跟 Audacity 4 比
  46. Steinberg Library Manager : 管理 VST 音色庫路徑與授權的工具
  47. SDU : 清理工具，我電腦剩下 200 G了
  48. UVR 5 : 去人聲
  49. Vibe : 生成字幕超好用
  50. Vital : 免費合成器！
  51. Vorssaint : 開源強大的工具彙整工具，只能說太強大了
  52. Vovious : 調音準很方便，請別買了，用 WiPitch就超讚
  53. Waveform : 搭配社團使用，超級男用
  54. XO : 把我電腦的所有鼓的 Sample 變成資料庫，方便找類似的酷工具
  55. Zed : 用來替代 VSCode ，更輕量、簡單！
